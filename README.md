# Snapmint-Merchant-Dasboard
Merchant Self-Serve Dashboard

A self-serve analytics portal for Snapmint merchant partners. Gives merchants real-time visibility into EMI sales, settlement status, customer repayments, and account settings — without contacting support.

Built as a product proposal and interactive prototype for Snapmint's product leadership team.

Stack: React · Recharts · shadcn/ui · Tailwind CSS
